Today, most private tutors still track student marks manually through books or spreadsheets. This is time-consuming and error-prone. So, we created SMART-KIDS — a digital platform that automates quizzes, evaluations, and student progress tracking. This function focuses on the progress and assessment tracking, which ensures students and tutors can see real-time results instantly. Tutor Dashboard – tutors can create quizzes, view submissions, and assign marks. Student Dashboard – students can attempt quizzes for their grade and view instant feedback. Progress Panel – automatically calculates marks, averages, and displays performance using clear visual indicators.”
We focused on creating a very clean and user-friendly interface. The layout uses clear sections, color-coded progress bars, and simple buttons for better navigation. Each input form includes validation alerts, so users can’t miss required details — improving accuracy and reducing errors.
